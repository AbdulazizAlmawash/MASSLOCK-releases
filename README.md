# MASSLOCK releases

Downloads for **MASSLOCK**, a trade cockpit for Elite Dangerous.

## Updating

You don't need to come here. MASSLOCK checks this page each time its launcher opens, and when a new version is out it shows **Install** under the MASSLOCK title. One click downloads it, checks it, installs it and restarts MASSLOCK. Your saves and profile are never touched.

You can also check by hand in the launcher: **Settings → Updates → Check now**.

## What is here

Each version in [Releases](../../releases) has two files:

- `masslock-app-<version>.zip`: the MASSLOCK app
- `masslock-update.json`: the version, its notes and a fingerprint MASSLOCK uses to verify the download

This repository holds only these downloads.
